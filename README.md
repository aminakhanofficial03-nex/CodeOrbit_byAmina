## Project overview

This beginner-friendly data science project demonstrates how to inspect and clean a CSV dataset, calculate descriptive statistics, and explore patterns using charts. The student-performance data is **synthetic and intended for learning only**; it is not real student data.

## Technologies used

- Python 3
- Pandas
- Matplotlib
- CSV

## Project files

- `main.py` — source code for data cleaning, descriptive statistics, and charts.
- `sample_student_performance_raw.csv` — sample input dataset with deliberate data-quality issues.
- `sample_student_performance_cleaned.csv` — cleaned dataset generated by the program (may be regenerated when the script runs).
- `outputs/` — generated charts and summary statistics after running the script.

## Features

- Loads the raw CSV dataset with Pandas.
- Detects and removes duplicate rows.
- Converts numeric columns to consistent numeric data types.
- Treats out-of-range values as missing.
- Fills missing numeric values using each column's median.
- Prints descriptive statistics and group value counts.
- Calculates the correlation between study hours and final scores.
- Generates a histogram, scatter plot, and group-average bar chart.
- Exports the cleaned CSV and summary statistics.

Make sure `main.py` and `sample_student_performance_raw.csv` are in the same folder, then run:

```bash

```

The script prints the cleaning summary and descriptive statistics. It creates an `outputs` folder containing the visualizations and `summary_statistics.csv`.

## Main cleaning decisions

1. Duplicate rows are removed.
2. Numeric columns are converted using `pandas.to_numeric`.
3. Study hours are validated within 0–24; attendance and scores are validated within 0–100.
4. Invalid or missing numeric values are filled using the column median.

Median imputation is used for demonstration. In a real project, the cause of missing or invalid values should be investigated and the imputation method justified.

## Key interpretation note

The dataset is small and synthetic. Any relationship between study hours and scores is descriptive only and does not prove that study time causes a score change. Results should not be generalized to real students.
